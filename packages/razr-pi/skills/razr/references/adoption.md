# Explicit safe adoption and discovery

Locate the package from the skill directory and resolve its helper/core paths. Read the target rules first. Verify that the intended target is already the exact Git root; do not silently initialize a real project. Only approved disposable tests may initialize their own repositories.

Inspect AGENTS.md, razr.yaml and the requested relative work root. Refuse linked or non-regular control files, linked work-root components, traversal, ambiguous/reversed/duplicate routing markers and modified managed routing. Preserve unrelated instructions and both ends of any link. The wrapper is not an adversarial concurrent path-swap sandbox.

After explicit human authority for this target, invoke `scripts/adopt.py` using an argument array with `--target` and `--work-root`. It delegates initialization to the bundled unchanged core. Never bypass its safety checks with direct core initialization.

Run bundled core `status --json` and `validate --all` from the adopted root. Separately authorized discovery uses `idea` with the intended identifier, title and depth. Inspect configuration, routing and the newly created spec.md, then rerun status and validation. A subprocess error is a stop, not success. Validation is not product-test evidence.

No target-project state belongs in this reusable package. Stop before approval or live task/candidate/review actions. No automatic routing repair, installation, model invocation or publication is supported. Preserve retained evidence and unrelated repository content.
