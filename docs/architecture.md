# Architecture and authority

Pi loads the declared skill as instructions and the extension as executable command registrations. Loading either is not execution authority, adoption, or an approval sandbox. The adoption wrapper checks target control paths and delegates to the provenance-pinned Python core, which remains the sole lifecycle authority. M09 changes only its exact delivery-identity gate; M10 changes documentation and package metadata only. No adapter, extension, host, or model runtime owns lifecycle state.

The core owns lifecycle state and legal generation-fenced transitions. spec.md owns intent, executable.yaml the immutable approved DAG, state.yaml materialized progress, and evidence.md actual reproduced observations. Before approval, discovery has only spec.md. Never hand-edit lifecycle state or mistake prepared metadata for actual human approval.

The normal product flow is idea or conversation → spec convergence → executable → build → verify → delivery. The repository is the primary project brain: source, tests, configuration, and Git outrank workflow notes and Razr Memory. No Project Brain, Obsidian, MCP vault, or separate architecture/component/session taxonomy is required. Memory records experience rather than a prose mirror of source; workflow artifacts are retained only as needed for intent and provenance.

The reusable package owns no target list or mutable project state. Helpers locate their core/templates relative to the package. Public tests own their temporary roots; installed Pi is an explicit external tool prerequisite, not bundled source or an implicit download.

Public inspection and preflight helpers do not execute tasks or grant authority. The complete core is preserved for provenance, not advertised as complete adapter automation. The extension registers only status, context, and Memory commands. The optional Herdr provider owns bounded host transport and append-only attempt evidence; its status never maps to Razr state. The GitHub helper owns bounded source-bound delivery observations and separately authorized creation; it never merges or infers review. Candidate identity and excluded-input scrutiny, fresh dual independent critique and human PR review remain required gates. Source-digest equality cannot substitute for exact commit equality: final PR head, candidate commit, and both reviewed commits must match. There is no background fleet, native subagent assumption, scheduler, general recovery dispatcher, critic dispatcher, or factory.

Comments explain non-obvious local intent and invariants only; tests preserve behavioral memory, while Git and Razr Memory preserve history and rationale. Memory is advisory, repository-scoped, bounded, and heuristically secret-filtered; it is not a confidentiality boundary or a source mirror. Existing legacy Project Brain/Obsidian/MCP-vault hooks may be ignored or migrated deliberately, but are not silently rewritten or made authoritative. Historical workshop evidence remains historical and is never imported as current proof.
