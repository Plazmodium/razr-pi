# Capability boundaries

This public source candidate implements safe adoption/discovery, bounded context and local-first Memory through the Pi package, plus selected no-model regression mechanics. Its supported guidance follows idea/conversation → spec → executable → build → verify → delivery without requiring Project Brain, Obsidian, an MCP vault, or a parallel documentation brain. Acceptance of a reviewed source identity, independent critique and actual post-import clone verification are separate gates; no historic acceptance is inherited.

The integration tracer checks source/provenance, an actual installed Pi local-package resolver with no model/client construction, explicit safe adoption, discovery, core status/validation and unchanged relocated package bytes. Exactly one package skill and one Razr extension are permitted; prompts, themes, and context files remain absent. Loading does not adopt or authorize writes.

The selected public suite covers adoption refusal/idempotence/separation/relocation, loader refusal/no-adoption, synthetic contract preflight, core-materialized synthetic work inspected read-only, stale-generation refusal, source/provenance and privacy boundary refusals, deterministic bounded M03 context selection (including stale Memory, safe paths and omission markers), and collector test/subcase behavior. Core approval in a fixture uses explicitly synthetic metadata and never represents a real human decision. No lifecycle state is hand-written.

Lab-bound review, retained-run recovery, local-history admission and automatic PR/factory capabilities are deliberately absent. Excluding their dependencies does not prove portable replacements. No historical test aggregate, review outcome or model allowance transfers here. Runtime core commands beyond the public adapter's scope remain present only to preserve the unchanged snapshot, not to grant execution authority. Existing legacy brain/vault hooks are compatibility inputs to migrate or ignore explicitly, never hidden requirements.

Missing prerequisites and declared fixtures are failures, not passing skips. Pattern scanning and hashes are not confidentiality certification, approval authentication or a sandbox. Review all source before publication. Tests run from an allowlist-only materialized tree without historical data; that is not a freshly cloned published repository. Actual post-import clean-clone execution, exact-source review, fresh independent Technical/Contract critique and human final review remain required. No publication or factory work is authorized by passing tests.
