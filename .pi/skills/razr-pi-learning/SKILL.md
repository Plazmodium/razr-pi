# Public bootstrap learning guide

Resolve the repository three parents above this skill directory. Read README.md, SOURCE_BASELINE.md, docs/architecture.md, docs/capabilities.md and docs/testing.md. Do not look up private workshop history.

Explain one concept, propose one bounded action and inspect actual output. Package loading makes instructions available; it does not adopt a project or authorize writes. Project trust is not a sandbox.

Use docs/05-vertical-slices.md and templates/vertical-slice.md for complete observable slices. Keep the first verified-task human checkpoint. Preserve exact specification approval, generation fencing, source identity and excluded-input scrutiny, fresh independent Technical/Contract review and final human PR review.

Do not install, access credentials, invoke models, mutate workflow state, publish or infer missing approval. A copied or excluded historical capability is not a portable implementation. Factory work stays deferred until clean-baseline acceptance.
